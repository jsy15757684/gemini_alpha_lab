# 🚀 Gemini Alpha Lab (AI 퀀트 & 스마트 인베스트먼트 리서치 OS)

시간을 투자하여 실질적인 투자 수익과 2차 콘텐츠(유료 리포트) 수익을 창출할 수 있는 차세대 AI 퀀트 리서치 플랫폼입니다.

---

## 🌟 핵심 기능 및 수익화 가치

1. **실시간 마켓 레이더 & Gemini 감성 분석**
   - 글로벌/국내 주식 및 주요 가상자산 시세, 이동평균선(SMA 20/60), 볼린저 밴드 지원
   - Gemini AI 기반 마켓 감성 점수 (0~100점), 3대 호재 및 리스크 요인 즉시 진단

2. **자연어 퀀트 전략 빌더 & 백테스팅 시뮬레이터**
   - 일상 언어로 입력한 투자 아이디어를 퀀트 파라미터로 자동 파싱
   - 연간 수익률(ROI), 벤치마크 대비 초과 수익률(Alpha), 승률, MDD(최대 낙폭), 샤프 지수, 매매 체결 일지 시각화

3. **기업 재무 엑스레이 (Filing Deep-Dive)**
   - PER, PBR, 성장 잠재력, 기관 수급 추이 및 재무 건전성 진단

4. **프리미엄 유료 분석 리포트 자동 생성기 (2차 콘텐츠 수익화 파이프라인)**
   - 분석한 전략 및 팩트를 클릭 한 번으로 기관 투자자 수준의 유료 뉴스레터/외주용 포맷(Markdown/HTML)으로 생성
   - 서브스택, 크몽, 네이버 프리미엄콘텐츠에 즉시 유료 발행 가능

## ⚡ 빠른 시작 (실행 방법)

터미널에서 아래 스크립트를 실행합니다:

```bash
cd /Users/jay_mac/gemini_alpha_lab
./run.sh
```

또는 직접 실행:

```bash
cd /Users/jay_mac/gemini_alpha_lab
/Users/jay_mac/my_ai_system/ai_env/bin/python3 -m uvicorn server:app --host 0.0.0.0 --port 8888 --reload
```

실행 후 웹 브라우저에서 **`http://localhost:8888`** 에 자동으로 연결되며 즉시 모든 기능을 사용하실 수 있습니다.
